# Excel UDF Lib README Ver2.0.x

## Excelをもっと便利に、もっとシンプルに。

Excel UDF Libでは、Microsoft Excelで利用できるユーザー定義関数（UDF）を開発し、UDFライブラリとして公開しています。

このライブラリは無保証で提供していますが、どなたでも無償で利用できます。

Excel標準関数にはない機能を追加するとともに、標準関数やVBAで実現できる処理でも、より簡単で分かりやすく利用できる環境を目指しています。

UDFは、利用者がVBAコードを書くことなく、通常のExcel関数と同じ感覚で利用できます。

# 1. Excel UDF Libとは

Excel UDF Libでは、Excel標準関数にはない機能を追加するとともに、標準関数やVBAで実現できる処理でも、より簡単で分かりやすく利用できる環境を目指して、ユーザー定義関数（UDF）を開発しています。

開発したUDFはライブラリとしてGitHubで公開しており、どなたでも無償で利用できます。

Excel UDF Libでは、Excel作業で発生する「少し面倒」を減らし、利用者が必要な機能をすぐに使える環境を提供することを目指しています。

---

# 2. 主な特徴

Excel UDF Libは、Excel作業で発生する「少し面倒」を解決するためのUDFライブラリです。

## 2.1 Excel標準関数にはない機能を追加

Excel標準関数では取得が難しい情報や、通常のExcel操作では確認しにくい情報をUDFとして提供しています。

## 2.2 既存の処理をより簡単に利用

Excel標準機能やVBAで実現できる処理でも、毎回調べたりコードを書いたりする必要があるものもあります。

Excel UDF Libでは、それらの処理をExcel標準関数のように分かりやすく利用できるようにしています。

## 2.3 Excel関数と同じ感覚で利用

UDFは、利用者がVBAコードを書くことなく、通常のExcel関数と同じように利用できます。

## 2.4 必要な機能だけ利用可能

Excel UDF Libでは、必要なUDFをモジュール単位で追加して利用できます。

用途にあったUDFの利用は当該Moduleの追加をお願いします。

## 2.5 継続的な改善

Excel UDF Libは、より役立つライブラリを目指し開発に尽力していきます。

# 3. Excel UDF Lib利用方法概要

Excel UDF Libは、利用環境や用途に合わせて、2つの方法で利用できます。

## 3.1 Excel UDF Lib導入済みExcelファイルを利用

Excel UDF Libで開発したUDFをまとめて利用する場合は、GitHubで公開しているUDF設定済みExcelファイルを利用することで手軽に導入できます。

※利用する機能により、対応するExcelバージョンが異なります。VBAを使用できる環境が必要です。

## 3.2 必要なUDFのみ取り込んで利用

GitHubに公開されている各UDFファイル（`.bas`）から、必要なUDFをExcelファイルへ取り込んで利用できます。

利用する機能に合わせて、必要なUDFの追加をお願いします。

## 3.3 詳細な利用方法について

導入手順や設定方法については、別途ドキュメントを参照してください。

# 4. 動作環境概要

Excel UDF Libを利用するには、Excel VBAが使用できる環境が必要です。

また、利用するUDFにより必要とされるExcelバージョンが異なります。

UDFが正常に動作しない場合は、ExcelバージョンやVBA使用環境等が原因となる場合があります。

## 4.1 Excelバージョンについて

Excelバージョンにより、利用できるUDFに制限があったり、UDFの動作が意図した結果にならない場合があります。

特に以下の機能を利用するUDFでは、Excel365などのスピル機能に対応した環境が必要です。

- 複数セルの情報を一覧形式で取得するUDF
- 動的配列（スピル）を利用するUDF

対応状況の詳細については、別途ドキュメントを参照してください。

## 4.2 VBA使用環境について

Excel UDF Libでは、VBAで作成されたユーザー定義関数（UDF）を提供しています。

そのため、以下の環境では利用できない場合があります。

- VBAマクロが無効化されている環境
- 組織のセキュリティポリシー等によりマクロ実行が制限されている環境

利用する場合は、Excelの設定や組織のセキュリティポリシーを確認してください。

## 4.3 詳細な対応状況について

対応するExcelバージョンや各UDFの利用条件については、別途ドキュメントを参照してください。

# 5. 関数カテゴリ紹介

Excel UDF Libでは、Excelで利用できるちょっと便利なUDFを用途別に系統に分けて開発しています。

## 5.1 File系

ファイルに関する情報取得や確認を行うUDFを提供しています。

例：

- ファイル情報の確認
- ファイル一覧の取得

## 5.2 Sheet系

ワークシートに関する情報取得や確認を行うUDFを提供しています。

例：

- シート情報の確認
- シート一覧の取得

## 5.3 Cell系

セルの状態や情報を確認するためのUDFを提供しています。

例：

- セル情報や状態の確認

## 5.4 Table系

Excelテーブルに関する情報取得や確認を行うUDFを提供しています。

例：

- テーブル情報の確認
- テーブル一覧の取得

## 5.5 Color系

セルや文字色に関する情報取得や確認を行うUDFを提供しています。

例：

- セル色の確認
- 色情報の取得
